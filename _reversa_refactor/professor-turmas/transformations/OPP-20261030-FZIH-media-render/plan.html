Contexto: professor-turmas | Alvo: src/views/professor-turmas-notas.ts | Data: 2026-10-30

1. Lógica atual e por que é complexa

A mesma média é exibida por dois caminhos com regras diferentes. O render inicial mostra o valor cru; o recálculo mostra o valor arredondado. A complexidade é acidental: não existe regra de negócio pedindo dois formatos, apenas duas implementações que ficaram desalinhadas após a mudança de calcularMediaParcial.

// renderLinhaAluno - inicial
- const mediaCalculada = calcularNotaFinal(mediaParcial, notas.rec || 0);
- const recDisabled = mediaParcial >= 7 ? ...
- ... ${mediaParcial > 0 ? mediaParcial.toFixed(1) : "-"}

// recalcularMedia - após edição
- const mediaParcial = arredondarNota(calcularMediaParcial(n1, n2, n3));
- ... ${media > 0 ? media.toFixed(1) : "-"}

O PDF já faz o mesmo que o recálculo: arredondarNota(calcularMediaParcial(...)) em professor-turmas-pdf.ts:54. O render inicial é o único dos três caminhos que não arredonda.

2. Solução proposta

Aplicar o helper que já existe no render inicial, só para a coluna Média e para o bloqueio da Rec. A nota final continua calculada com a média crua, exatamente como hoje, para não alterar recuperação em nenhum caso.

// renderLinhaAluno
+ const mediaExibida = arredondarNota(mediaParcial);
  const mediaCalculada = calcularNotaFinal(mediaParcial, notas.rec || 0);
- const recDisabled = mediaParcial >= 7 ? ...
+ const recDisabled = mediaExibida >= 7 ? ...
- ... ${mediaParcial > 0 ? mediaParcial.toFixed(1) : "-"}
+ ... ${mediaExibida > 0 ? mediaExibida.toFixed(1) : "-"}

Nenhuma mudança em calcularNotaFinal, calcularStatusAluno ou no recálculo. A regra passa de duas para uma.

5. Rede de segurança

Estender src/views/professor-turmas-notas.test.ts com testes de renderLinhaAluno lendo as células do DOM. Duas famílias: caracterização do que não muda (nota final, status, média zero, médias já múltiplas de 0,5) verde antes e depois; regressão do que muda (média crua que arredonda e bloqueio da Rec) vermelha antes e verde depois. A tabela de casos acima é a fonte das asserções.

Rodar npm test -- professor-turmas-notas e npm run type-check antes e depois.
